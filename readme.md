## 시스템 개요

| 항목 | 내용 |
|---|---|
| 버전 | v8.0 |
| 스택 | React 18 JSX (단일 파일) + Vite |
| 마지막 업데이트 | 2026-07-29 |
| 검증 견적서 | **99장** (`docs/` 21 + `docs/기타/` 78) |
| 역산 근거 문서 | [docs/견적서_역산_분석.md](docs/견적서_역산_분석.md) |

**출력 항목 순서:** 공정합계 → 개발비 → 개당단가 → 총공급가액 → 부가세 → 합계

- **개당단가** = `round(공정합계 ÷ 수량)` — 개발비·부가세 별도
- **지대 공급가액** = `round(지대R × 지대단가)`
- **부가세** = 총공급가액 × 10% 별도 표기

## 주요 기능

- 박스 규격(W×D×H) → 전개도 치수 자동 계산 (맞뚜껑·십자조립·삼면접착·G형)
- **전개도 전체크기 직접 입력** — 슬리브·손잡이형처럼 공식이 없는 구조 대응
- 지종·판형 자동 추천 (총비용 최소 기준)
- 배치 시각화 (인터로킹 포함) · 전개도 미리보기
- 수량별 개당 단가 비교표 · 판형별 지대비 비교
- 지대R / 여분(손지) / 지대 단가 / **판걸이(up)** 각각 수동 오버라이드
- **행거탭(유로홀)** 옵션 — 피치에 안 더하고 외곽에만 1회 가산
- 주문생산 원지 (크기·절수 직접 입력)

## R수 계산

### 지대 R수
```
정미(net) = ceil(수량 / up)
지대R     = (정미 + 여분) / (500 × 절수)
            전지급(절수 1) → 0.1R 단위 올림 (= 50장 묶음)
            2절 이하      → 소수 3자리 올림
```
> 전지급 실측 R수는 **전부 0.1 배수** (2.6 / 4.0 / 1.8 / 2.8 / 4.6 / 4.8 / 6.8 — 7/7 일치).
> 46전지는 1R = 500장이라 0.1R = 50장 묶음 단위로 주문.

### 여분(손지)
```
여분 = max(기본, 정미 × 5%)         ※ 전부 "장수" 기준 — up을 곱하면 EA 환산
  기본 300장 (인쇄 없이 박·톰슨만이면 200장)
  + 양면인쇄 100장   + 베다(바탕인쇄) 100장   + 형압 50장
  ※ 박(금박·먹박)은 가산 없음
```

**EA 환산** — 여분은 장수 기준이라 up 수만큼 EA가 늘어남

| 46전지 3up | 정미 | 여분(장) | 총장 | ×3up = 총EA | 여분 EA |
|---|---|---|---|---|---|
| 3,000ea | 1,000장 | 300장 | 1,300장 | **3,900** | **900** |
| 5,000ea | 1,667장 | 300장 | 1,967 → **2,000장** (0.1R 올림) | **6,000** | **1,000** |

→ 견적서 실측과 일치 (2.6R / 4.0R)

| 규칙 | 근거 |
|---|---|
| 기본 300 | 정미 6,000장 이하 전건이 정확히 300장. 삼면E 견적서에 `500-300` 메모가 직접 남아 있음 |
| 양면 +100 | 십자B 한 장 안에서 직접 대조 — 양면 400 / 단면 300 |
| 베다 +100 | G형C 별1베다+먹 → 여분 400 (독립 2건) |
| 인쇄없음 200 | 트레이B(인쇄 무) 500ea → 700장 = 0.35R (정확 일치) |
| 박 가산 없음 | 조립형 금박 2건이 여분 300 — 금박은 손지 증가 없음 |
| 대량 5% | 정미 8,334 → 416 / 15,000 → 700 |

### 공정 R수 (인쇄·코팅·톰슨·박·형압·재단)
```
공정R = ceil( 정미 / 1000 × 10 ) / 10       ← 판형·절수 무관, 0.1R 올림
정미 < 1000장 → 1식 (최소 1R)
```

> **지대R은 절수 기준**(판형마다 1R 장수가 다름), **공정R은 무조건 1,000장 = 1R**.
> 반올림이 아니라 올림 (8.334 → 8.4)

## 인쇄비 계산

```
원색·먹 : 인쇄수량 = ceil(공정R × 도수) × 도당단가
별색    : ① 도수환산 → ceil(공정R × (별색도수×3 + 원색·먹도수)) × 도당단가   ← 기본
          ② R당 고정 → 공정R × 별색R단가 (일반 50,000 / 베다 75,000)
UV      : 수량 티어 고정가 (도수 무관, 별도 UV기계)
```

**별색 1도 = 인쇄 3회** — 삼면E 견적서 3장이 같은 박스·같은 수량인데 인쇄만 다름:

| 견적서 | 소부 | 인쇄 수량 | 금액 |
|---|---|---|---|
| 260526_별색2도 | 별2 (2도) | **6** × 14,000 | 84,000 |
| 260526_원색4도 | 원4 (4도) | **4** × 14,000 | 56,000 |

**UV인쇄 고정가**

| 수량 | 단가 |
|---|---|
| ≤ 3,000ea | 200,000 |
| ≤ 5,000ea | 250,000 |
| ≤ 10,000ea | 350,000 |
| 초과 | 수량÷1,000 × 35,000 |

**소부** = 도수 × 12,000원 (양면은 앞·뒤 합산). UV인쇄는 소부 없음.

## 물림 · 인쇄기 · 판걸이 수율

견적서 「단위」 열이 실제 재단 크기라서 여기서 역산됨.

| 항목 | 값 | 근거 |
|---|---|---|
| **물림(gripper)** | 짧은변 **−30** / 긴변 **−20mm** | 협력사 산출식 엑셀 「제작 규격(여분제외)」 (국이절만 −33) |
| **배치 허용오차** | **0.5%** | 전개도 공식 정확도 ±5mm 흡수 |
| **맞물림 (가로/세로)** | **10mm / 바닥날개** | 세로는 고정값 아님 — 바닥날개 깊이만큼 물림 |
| **인쇄기 최대 판** | **990 × 720mm** | 「단위」 20종 전건이 이 안에 들어감 (최대 990×590 / 980×720) |

| 재단 면적비 | 원지의 평균 **86%** | 소형(4절·국2·하4)은 100%, 전지급은 65~82% |

## 맞물림(interlocking) 판걸이

**출처:** `패키지 단가 산출식_엑셀_SB01_B형 맞뚜껑_190916_07.xlsx`
시트 `가격산출 조건표_SB01_B형 맞뚜껑` **D389:D396**

```
종이 재단 가로 : 1열 (가로+세로)*2+35
                2열 [ ]*2 − 10    3열 [ ]*3 − 20    4열 [ ]*4 − 30
종이 재단 세로 : 1열 (세로*2+높이)+50
                2열 [ ]*2 − 25    3열 [ ]*3 − 50    4열 [ ]*4 − 75
```

→ 열이 늘 때마다 **일정량이 선형으로 누적 차감**됨:

```
n열 총길이 = base × n − 맞물림 × (n−1)
```

| 축 | 맞물림 | 원인 |
|---|---|---|
| 가로 (netW 반복) | **10mm / 열** | 접착날개끼리 겹침 — 엑셀 값 그대로 |
| 세로 (netH 반복) | **= 바닥날개 깊이** | 뚜껑 혀가 상대 바닥날개 사이로 파고듦 |

### 세로 맞물림은 고정값이 아님 — 바닥날개 깊이만큼 물린다

엑셀의 `25mm` 는 B형 맞뚜껑(D=60, 바닥날개 ≈ 30) **한 케이스 값**.
구조·치수에 따라 크게 달라져서 견적서 10건으로 역산:

| 견적서 건 | 바닥날개 | IL_H 고정 25mm | IL_H = 바닥날개 | 견적서 |
|---|---|---|---|---|
| 삼면A 120×55×180 | 47 | 1up | **2up** ✓ | 2 |
| 삼면B 210×90×180 | 72 | 2up | **3up** ✓ | 3 |
| 삼면C 52×50×90 | 35 | 4up ✓ | 4up ✓ | 4 |
| ★삼면E 90×70×130 | 48 | 2up ✓ | 2up ✓ | 2 |
| 삼면F 90×90×250 | 54 | 2up ✓ | 2up ✓ | 2 |
| 십자A 47×47×176 | 47 | 6up ✓ | 6up ✓ | 6 |
| 십자B 70×70×55 | 67 | 4up ✓ | 4up ✓ | 4 |
| 맞뚜껑A 92×13×140 | 30 | 6up ✓ | 6up ✓ | 6 |
| 삼면D 82×7×126 | 26 | 4up | 4up | 2 |
| 맞뚜껑B 150×20×150 | 37 | 4up | 4up | 2 |
| **up 일치** | | **6/10** | **8/10** | |

### ⚠ up은 기하학으로 확정되지 않음

엑셀 공식이 자체 예시는 완벽히 맞는데, 실제 견적서 up과는 **양방향으로** 어긋남:

| 건 | 계산 최대 up | 견적서 up | |
|---|---|---|---|
| 맞뚜껑A 92×13×140 (국2) | 4up | **6up** | 계산이 작음 |
| 맞뚜껑B 150×20×150 (4×62) | 4up | **2up** | 계산이 큼 |

**up은 기하학 최대치가 아니라 실제 목형(die) 설계 결과.**
자동계산은 "최대 가능치"로만 쓰고, 발주서·기존 목형의 up을 알면
**「판걸이(up) 직접 입력」** 을 쓰는 게 정확함 (1·2·3·4·6·8·12up 프리셋 제공).

> 검증: 맞뚜껑A에 6up 직접 입력 → 정미 1,667 · 지대R **1.967** (견적서 1.92, Δ0.047R)
> 자동(4up)은 2.80R로 크게 벗어남.

| 삼면접착 (자동바닥) | `H + 1.2D + 0.25W + 31.5` | 9건 | 2.0mm | **5.1mm** | 68.8mm |

뚜껑쪽   = 0.88·D + 0.09·W + 20.6
바닥날개 = 0.33·D + 0.15·W + 11.0    ← 대각 크래시록이라 W에도 의존
netH     = H + 1.2·D + 0.25·W + 31.5

### 맞뚜껑 (2건) — 종전 −67.5mm

```

```

| 칼선 | W×D×H | 실측 세로 | 공식 | Δ | 종전 Δ |
|---|---|---|---|---|---|
| 칼선-07 240701 | 150×69.5×149 | 321.0 | **321.0** | **0.0** | −67.5 |
| 칼선-08 240701 | 150×69.5×219 | 391.0 | **391.0** | **0.0** | −67.5 |

칼선-07 접는선 실측: `[탭 19.0][뚜껑 21.0+45.5=66.5][몸판 H][66.5][19.0]`
(66.5 ≈ D−3 여유, 19.0 = 텍탭)

### 「수율」 vs 「발자국」 — 배치 판정 기준 변경

맞물림 배치에서는 `netW×netH` 가 전개도의 **빈 모서리를 포함**하므로
`up × netW × netH ÷ 판형`(=수율)이 실제보다 과대평가된다.

| 예 | up | 수율 | 발자국 |
|---|---|---|---|
| 맞뚜껑A 국2 회전 3×2 | 6up | **90%** | **82%** |
| 삼면E 4×64 회전 2×1 | 2up | 83% | 82% |

→ 배치 가능 판정은 **발자국(배치 외곽 ÷ 판형, 상한 92%)** 으로 함.
종전 85% 수율 컷은 견적서와 일치하는 맞뚜껑A 6up 을 잘못 걸러냈음.

### 행거탭 (유로홀 걸이)

다이소 등 걸이봉에 거는 유로홀 탭. **위쪽 한 곳만 돌출**하므로 맞물림 배치에서
옆 열의 빈 공간에 끼워진다 → **열 간격(피치)에는 안 더하고 전체 외곽에만 1회** 더한다.

| 모델 | 행거탭 | up | 배치 | 견적서 6up |
|---|---|---|---|---|
| 외곽에 1회만 (채택) | 0 / 15 / 20mm | **6up** | 회전 3×2 | ✓ |
| netH 에 그냥 합산 | 15mm | 4up | 정방향 2×2 | ✗ |

**맞뚜껑A 92×13×140** 은 위쪽에 행거탭 15mm가 올라가 있는 건.
전개도는 224.3×**214.0** (몸판 199.0 + 행거탭 15.0)로 커지지만
**6up · 지대R 1.97** 은 유지 → 견적서(6up · 1.92R) 일치.

> UI: `행거탭 (유로홀 걸이)` 토글 + 돌출 mm 입력 (기본 15)

### 남은 2건

전개도 공식(±5mm) + 세로 맞물림 일반화 후 견적서 up 재현 **8/10**.

| 건 | 계산 | 견적서 | 원인 |
|---|---|---|---|
| 삼면D 82×7×126 | 4up | 2up | **D=7** — 칼선 검증범위(D 33.75~124) 밖. 전개도 과대추정 |
| 맞뚜껑B 150×20×150 | 4up | 2up | 어떤 맞물림 값으로도 2up 안 나옴. 500ea 소량이라 기존 2up 목형 사용 추정 |
